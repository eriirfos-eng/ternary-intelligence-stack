# ternlang-compress

LLM-to-ternary compression pipeline — quantize float models to {-1,0,+1}, build sparse zero-index, export .tern files for ternlang-ml inference.

## Installation

```toml
[dependencies]
ternlang-compress = "2.0.0"
```
