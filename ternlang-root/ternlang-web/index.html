RFI-IRFOS · Ternary Intelligence Stack

The world isn't
binary.

A programming language and execution VM built on balanced ternary logic: −1, 0, +1. The zero state is a first-class instruction, not an error condition.

Why Three States

You already think in three states.

Your software doesn't. Here's the cost.

The structural problem: Binary ML systems must return an output even when evidence is insufficient. Ternlang encodes a third return state — trit = 0 — meaning "confidence below commit threshold." This eliminates the architectural cause of LLM hallucination: forced binary resolution under uncertainty.

Engineering

A traffic light with only two states causes accidents.

Red and green are not sufficient. Yellow is not an error — it is the correct output for a system in transition. Most distributed system failures happen during state transitions that binary logic cannot represent.

In practice: The BET VM instruction THOLD suspends the program counter and gates the ALU clock while a state is volatile. This is a deterministic mutex with no speculative branch — the CPU simply does not execute the conflicting instruction.
Medicine

Clinical hold is not a refusal. It is a protocol.

When a physician orders additional workup, that is the correct decision given the available data. Binary inference systems are not allowed that answer. trit = 0 is a machine-readable escalation signal, not a failure state.

In practice: The MoE-13 Safety gate returns trit = 0 when confidence falls below the commit threshold. The calling system receives a typed "insufficient evidence" response and routes to a human escalation handler or secondary inference pass — instead of fabricating an answer.
Law

"Insufficient evidence" is a verdict.

A case dismissed for insufficient evidence is a valid verdict, not a system error. Standard ML architectures have no type for this. Ternlang's trit type gives ambiguity a concrete numerical value that propagates through the call stack.

In practice: trit is a 2-bit type: {−1, 0, +1}. It is not a float, not a nullable bool. The compiler enforces exhaustive 3-way match — if your code doesn't handle the zero case, it does not compile. Uncertainty becomes a handled code path.

Governance & Observability

TernAudit.

Your model makes thousands of decisions per day. TernAudit logs every trit=0 hold and trit=−1 veto with full trace: which expert fired, at what confidence, on what input. No silent overrides. No guessing after the fact.

Evidence Graph

See exactly which input dimensions pushed — or failed to push — your agent's confidence above threshold. Real-time, during inference. Not a post-mortem. You watch the decision form.

Veto Trace

Safety fired a −1 block. TernAudit gives you the expert name, its confidence score, and the exact input vector that triggered it — timestamped, permanently logged to AxisMemory. You don't debug it. You read it.

Resolution Path

Agent stuck on trit=0? TernAudit generates a typed evidence request: the exact dimensions that are under-threshold and what value they need to resolve. You supply the data. The hold clears. No guesswork, no manual log trawl.

RFI-IRFOS Protocol Specifications

Open proposals — not yet ratified by external standards bodies. Published for community review and adoption.

TSON↗
Ternary serialization format. 2-bit trit packing is ~30% denser than JSON float64 for numerical payloads.
TTP↗
Transfer protocol with a hold-state response code (000) for in-progress deliberation. Replaces timeout errors with structured wait.
T-POSIX↗
OS interface standard: ternary process signals, 3-state scheduler, and trit-valued syscall return codes.
BET-ISA↗
9-trit RISC instruction set architecture. 51 opcodes, 27 registers, THOLD as a first-class pipeline gate.
T-BIO↗
Genomic sequencing standard: methylation, expression, and SNP states encoded as trit arrays.
T-SEC↗
Post-quantum cryptography spec: ternary lattice key exchange and trit-valued signature verification.
