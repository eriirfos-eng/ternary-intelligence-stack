The software and compiler ecosystem deficit ends here. The compiler structurally enforces exhaustive matching on the {-1, 0, +1} continuum, mapped directly to 11 native crates running on the BET VM.

Ecosystem Crates

ternlang-core LGPL

Lexer, parser, and the native BET VM infrastructure.

ternlang-cli LGPL

Commands to run, build, simulate, fmt, and open the REPL.

ternlang-lsp LGPL

LSP 3.17 server for complete IDE and VS Code integration.

ternpkg LGPL

Official package manager parsing native ternlang.toml manifests.

ternlang-compat LGPL

9-trit RISC assembler and Owlet S-expr bridge.

ternlang-ml BSL-1.1

Sparse matmul and BitNet quantization toolkits for the VM.

ternlang-moe BSL-1.1

The MoE-13 orchestrator and core AgentHarness routing.

ternlang-mcp BSL-1.1

MCP server exporting 10 native tools via HTTP and stdio.

ternlang-api BSL-1.1

High-throughput REST and SSE API integration.

ternlang-hdl BSL-1.1

Verilog-2001 code generation for direct FPGA simulation.
