2. What Data We Collect 2. Welche Daten wir erheben

When visiting ternlang.com, the following data is processed:

  • Server logs: IP address (anonymised after 24h), access timestamp, URL, HTTP status code, referrer, user agent. Legal basis: Art. 6(1)(f) GDPR (legitimate interest in operational security).
  • Theme & language preference: Stored as a localStorage entry in your browser (no cookie, no server access). Legal basis: Art. 6(1)(b) GDPR (user preference / service provision).
  • API usage: When using our REST API or MCP tools, API keys and request metadata are processed for billing and abuse prevention. Legal basis: Art. 6(1)(b) GDPR (contract performance).

We use no tracking cookies, no advertising networks and no cross-site tracking.

Beim Besuch von ternlang.com werden folgende Daten verarbeitet:

  • Server-Logs: IP-Adresse (anonymisiert nach 24h), Zeitpunkt des Zugriffs, aufgerufene URL, HTTP-Statuscode, Referrer, User-Agent. Rechtsgrundlage: Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an Betriebssicherheit).
  • Theme- & Sprachpräferenz: Gespeichert als localStorage-Eintrag im Browser (kein Cookie, kein Server-Zugriff). Rechtsgrundlage: Art. 6 Abs. 1 lit. b DSGVO (Nutzereinstellung / Vertragserfüllung).
  • API-Nutzung: Bei Nutzung unserer REST-API oder MCP-Tools werden API-Keys und Request-Metadaten zur Abrechnung und Missbrauchsprävention verarbeitet. Rechtsgrundlage: Art. 6 Abs. 1 lit. b DSGVO (Vertragsdurchführung).

Wir verwenden keine Tracking-Cookies, keine Werbe-Netzwerke und kein Cross-Site-Tracking.
