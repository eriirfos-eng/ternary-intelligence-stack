how it works
albert. reads text in 8 languages simultaneously and learns from all of them at once. At this stage it correctly activates domain knowledge — but has no mechanism yet to select which language to output in. The result is a multilingual token stream: domain-correct, language-mixed. The translate button above each reply runs that stream through Google Translate as a best-effort interpretation. Output changes as training progresses.
