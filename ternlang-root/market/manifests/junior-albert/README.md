# The Junior-Albert: Local TIS Gateway

**Junior-Albert** is a lightweight, local version of the Albert agent, serving as the primary gateway for developers and researchers to access the full Ternary Intelligence Stack (TIS).

*   **TIS Gateway:** Provides a direct interface for executing basic triadic logic and tensor operations locally.
*   **Substrate Connection:** Bridges local development environments with the full BET VM and TIS-MCP hardware-accelerated kernels.
*   **Project Initialization:** Automatically scaffolds new TIS-compliant projects with the correct triadic substrate and licensing.
