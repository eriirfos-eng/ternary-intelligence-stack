# The Guard: Real-Time Threat Detection

The **Guard** is a security-focused agent that provides real-time detection of anomalous network traffic before it escalates into a defined threat.

## Operational Overview
*   **Anomaly Detection:** Identifies traffic patterns that fall between "Safe" (+1) and "Threat" (-1), routing them to "Anomalous" (0) for secondary evaluation.
*   **Intrusion Mitigation:** Leverages triadic logic to "pend" suspicious connections without immediately terminating valid traffic.
*   **Behavioral Auditing:** Continuously scans project activity for patterns of non-standard usage or credential leakage.

## Key Benefits
*   **Proactive Defense:** Identifies threats in the "uncertain" stage where binary firewalls fail to trigger.
*   **Deterministic Safety:** Provides a layer of triadic security that is resilient against binary-based exploit vectors.
