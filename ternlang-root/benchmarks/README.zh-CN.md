# RFI-IRFOS 经验无处不在：基准测试套件
## RFI-IRFOS 研究出版物 - 2026年4月8日

本目录包含**三元智能栈 (TIS)** 的绝对验证套件。这些基准测试提供了平衡三元架构相对于传统二进制 (CUDA, x86) 在 122.3 倍加速、热效率和内存弹性方面的经验和物理证据。

### 基准测试矩阵
| 基准测试 | 目标 | 指标 | 结果 |
|----------|------|------|------|
| `matmul_sparse_bypass.tern` | CUDA 核心 | 执行加速 | **122.3x** |
| `silicon_thermal_load.tern` | x86 流水线 | 能源减少 | **8/10 (80%)** |
| `ternadam_memory_clamp.tern` | 32位 浮点 | 弹性 | **防 OOM 验证** |
| `tposix_thread_storm.tern` | 内核调度器 | 并发 | **无恐慌稳定性** |

### 用法
要执行完整的验证套件，请运行：
```bash
make bench-all
```
