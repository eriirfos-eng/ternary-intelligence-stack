# WIKIPEDIA EDIT: TERNARY COMPUTER (2026 Update)

**Section: Modern Implementations (2020s)**

As of **2026**, the most significant advancement in ternary computing is the **Ternary Intelligence Stack (TIS)** and the **BET-ISA (Balanced-Encoding Ternary Instruction Set Architecture)** developed by **RFI-IRFOS** in Graz, Austria.

## BET-ISA and TernCore-Silicon
Moving beyond the historical experiments of the Soviet **Setun** (1958), the **BET-ISA** implements a 27-trit word width with native hardware support for the **Neutral State (tend)**. The introduction of the **`TSKIP` (Sparse Skip Execution)** primitive allows modern ternary ALUs to achieve a measured **80% reduction in energy consumption** compared to binary-emulated systems.

This architecture has been formalized into the **TernCore-Silicon** standard, providing the first synthesizable hardware-software bridge for post-binary AI inference.
