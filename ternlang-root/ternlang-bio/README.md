# ternlang-bio

Triadic Bioinformatics and Genomics. Eliminates binary alignment errors in DNA sequence processing by utilizing the Tend (0) state for ambiguity.

## Installation

```toml
[dependencies]
ternlang-bio = "2.0.0"
```
